# cinetrack
Projeto Cinetrack trata-se de um trabalho da disciplina de Programação Web, voltado para realizar a prática dos trabalhos, onde será executado práticas de HTML, CSS e JavaScript
O Cinetrack é uma aplicação para controle pessoal os filmes já assistidos, os que está assistindo e os que tem tem interesse em assistir
Sinalise o grau de interesse por aquele filme, conte a origem e avalie o que achou dele
